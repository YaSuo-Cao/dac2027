# Anonymous release scope and integrity

This is a reviewed COPY of the unified experiment snapshot. The working
experiment directory was not edited. Personal account names, user-specific
absolute paths, private host/IP references, credential values, and provider
receipt identifiers are removed or pseudonymized. Git metadata, secret stores,
paper PDFs, old partial cohorts, temporary builds, process state, and machine
deployment settings are excluded. Public third-party copyright notices remain.

Core router, repair/contract/budget algorithms and the seven frozen runtime
files are preserved. Deployment-only adapters now use process environment
variables and local Docker. Receipt equality is preserved by stable public
pseudonyms, but original provider receipt IDs are not disclosed.

Original SHA256 fields describe the original experiment artifacts. Privacy
redaction and text normalization can change exported file/record bytes. They
must not be interpreted as a failed research audit or silently equated with
the original hashes. MANIFEST.json authenticates the PUBLIC bytes; compact
evidence records give both original-byte and public-text SHA256. The original
final_audit.json is a historical audit report, not a checksum manifest for
this anonymized distribution. verify_artifact.py is the public release audit.

The export preserves numeric results, denominators, sampling parameters,
token usage and statistical tables. No experiments were run or rescored.
Saved construction_events, native wrapper/probe console logs, binary builds,
and emitted Verilog trees are omitted where their information is duplicated
by structured gates, results, JUnit, traces, counterexamples and source.
Infrastructure retry history remains in sanitized analysis ledgers; archived
failed build trees are not redistributed. This is sufficient for saved-data
analysis; an exact reconstruction of the original private host is not claimed.

No upload or external publication is performed by the local packaging tool.
